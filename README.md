# SmartBudget Manager

* A simple Excel workbook for tracking personal income, expenses, and budget limits.


* What it does
- Records income and expenses in a transaction table.
- Categorizes expenses using predefined categories.
- Calculates total income, total expenses, and balance.
- Compares expense totals with category budgets and shows a budget status.
- Displays expense information on a Dashboard, including a chart.

* What you need
- Microsoft Excel 2016, 2019, 2021, Microsoft 365, or a compatible spreadsheet application.
- Basic skills: open/save a workbook, select a cell, and enter data.

* Get started
1. Save a copy of  in a folder you can find again.
2. Open the **Transactions** worksheet.
3. For each transaction, enter the date, description, type, category where applicable, and amount in the correct Income or Expense column.
4. Use the drop-down lists when available. Enter either an income or an expense for a transaction, not both.
5. Open **Categories** to review or adjust the monthly budget amounts.
6. Open **Dashboard** to review totals, category spending, remaining budget, status, and chart.
7. Save your changes ().

* Important notes
- Do not overwrite the calculated **Month** column or formula cells on the Dashboard.
- The workbook's current summary formulas total the populated transaction range; they do **not** automatically filter results to a selected month.
- The main totals currently reference transaction rows 4–50. If you need more rows, extend the table and formulas carefully or ask someone familiar with Excel.
- Keep a backup copy before changing formulas or worksheet structure.
- The workbook is a budgeting aid, not professional accounting or financial advice.

* Workbook sheets
- **Dashboard** — totals, balance, budget status, category summary, chart.
- **Transactions** — transaction entries and calculated month.
- **Categories** — predefined expense categories and monthly budget amounts.
